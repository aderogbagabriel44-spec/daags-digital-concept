# Daags Digital Concept Website

Premium multi-page static website for Daags Digital Concept.

## Structure
- Home
- About
- Services
- Website Design
- Portfolio & Gallery
- FAQ
- Contact
- Privacy Policy
- Terms & Conditions

## Deployment
Upload the project files to a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from a branch → main → / (root).

## Replace before launch
- Portfolio/gallery placeholder images
- Project descriptions
- Final business/about copy
- Privacy policy and terms
- Any service-specific requirements/pricing
- Contact/social links if they change
